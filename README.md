# HTML & CSS Course Assignment - Rainy Days

This project is my submission from the course assignment for HTML & CSS in Noroff school of digital media and technology FED 1 programme.
My first ever coding project featuring only vanilla HTML and CSS.
This project is not applicable for professional use and should be viewed as a sandbox for my learning development in my first year studies.

The course assignment brief gave us CA files for product images and logo for a fictional e-commerce brand, Rainy Days.
Our task was to take our design project from the previous course and create a static website with vanilla HTML and CSS only.

This website lacks full functionality with adding products to a cart system. Each page should be viewed as a mock of what a real world application could look like.

This project was originally not deployed for the course assignment. Later on in the Portfolio 1 course, this project was revisited and made some improvements to. The project still needs a lot of work, and should be created again from scratch to be fully professional and presentable.

## Features

- Index page with product list
- Single product details page for each product
- Cart/checkout page
- Confirmation page
- Construction page for pages that were not completed in time
- Interactive carousel slideshow with use of radio buttons and animation
- Hamburger dropdown menu with use of max-width/auto overflow CSS trick
- Full responsive scaling across viewports from 320px VW to 1920px VW, with use of clamp() and @media breakpoints
- Implementation of icons and fonts via FontAwesome free library scripting
